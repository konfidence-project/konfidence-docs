## Current versions

Refer to the official Konfidence repository and release notes for current version information and compatibility matrices.

## Release schedule

Konfidence follows a regular release schedule with:

- Major versions for significant feature additions
- Minor versions for new features and enhancements
- Patch versions for bug fixes and security updates

## Upgrade paths

### Supported upgrade paths

- Always upgrade to the latest patch version within your current minor version
- Plan upgrades between minor versions during scheduled maintenance windows
- Major version upgrades may require additional planning and testing

### Version compatibility

Ensure compatibility between:

- Galaxy and Star versions
- Deployers and Konfidence core
- Custom extensions and core version

## Release notes

Each release includes:

- New features and enhancements
- Bug fixes and security patches
- Breaking changes and migration guides
- Dependency updates
- Known issues
